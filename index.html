你可以用它做什么

  • 多领域学习问答

    选择通识、数学、科学、医学课程或编程概念等学习情境，写下问题和学习目标，按入门或进阶深度获得分步讲解，数学公式会正常排版。

    医学内容仅用于课程学习，不提供个人诊疗建议。

  • Python 沙箱调试

    贴上代码，填写输入与期望输出。原代码和修改建议都会在隔离沙箱里用你的样例实际运行，并逐条对比结果。

    样例通过只说明你填写的情况，不等于程序完全正确。

  • 可追溯的回答

    每次回答都会标明实际作答的模型、执行过程和局限说明；任务进度、失败原因与取消状态如实显示，方便你核对和复盘。

    回答由模型生成，可能有误，请结合教材核对。

关于这次体验

当前体验接入 3 个 API 模型，由 CPU 门控为每个问题选择其中一个作答；不声称相对单模型有提升。

  • 一次请求，一个模型 学习问答可在 3 个 API 模型间智能路由：CPU 门控依据新测量的能力画像选择一个模型，每个问题只调用一次；也可以固定使用基准模型对照。页面会显示服务商回报的实际模型名称。能力画像来自小规模校准题，不代表回答一定更准确。
  • 临时服务 在线体验依赖后端服务保持在线，属于临时部署；服务离线时入口可能无法打开或无法提交，请稍后再试。
  • 账号与隐私 本页面不收集任何账号或密码。如需登录，会在在线应用内完成。请不要在问题中填写个人隐私信息。
